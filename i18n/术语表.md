# 术语表 v1（待确认）

汉化前先把用词钉死，避免九百多个节点翻完再返工。**加粗的是我拿不准、想让你拍板的**。

## 一、总风格

| 项 | 约定 | 理由 |
|---|---|---|
| 语气 | 短、口语、能省就省 | 原文本身极简（`x2 points.` `boost energy gain`），翻长了节点框装不下 |
| 长度 | 中文控制在原文视觉长度内 | canvas 节点框尺寸固定，挤出去会盖住相邻节点 |
| 句末标点 | 照抄原文：原文有句号就加，没有就不加 | 出现率高，统一才不显乱 |
| 数字与单位 | **不加空格**：`+2/秒`、`x1.25`、`5 级` | 中文习惯，且省宽度 |
| 乘号 | 统一用**小写 x**，不用 `×` | 游戏里有个货币就叫 `×`（Multiplications），用 × 会歧义 |
| 编号 | `#01`、`#32`、`CCC01` 原样保留 | 是坐标标识，不是文案 |
| 叠词/梗名 | 意译保梗，不强求直译 | 大量节点名是玩笑（`woah!` `yes!` `what`），硬翻反而怪 |

## 五、已确认（v1 定稿）

1. **boost → 增幅**。出现 155 次，旧译"提升/加强"不再使用。
2. **Alpha / Beta 一律保留原文，绝不音译成「阿尔法 / 贝塔」**。货币名写 `Alpha` / `Beta`；原文用符号的地方（如 `+1α/s`）译文也保留符号 `α` / `β`。同类希腊字母（δ、γ 等）照此处理。
3. **Plates 货币 → 板块**；baseplate / plate 指树的区块 → **底板**。同源词按语境分开。
4. **梗名按"玩家随口感叹"的调子译**：`woah!` → 哇哦、`yes!` → 好耶、`what` → 啥。不追求字面准确。
5. **piece 依语境**。全库仅 24 处、同一句 `get a piece of thing per upgrade in this plate`，此处取"一块东西"（本底板每升级一次得一块东西），**不与货币 Fragment「碎片」混用**；`piece by piece` → 一点一点。
